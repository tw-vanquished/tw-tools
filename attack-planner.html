🚀 First Setup

1 Village Database

Nothing to download or set up — the planner fetches the world's village and player data automatically every time you open it, so village names, IDs and player data are always up to date.

You can browse and search the loaded data in the Village DB tab.

2 Configure world settings

In the top bar, set World Speed and Unit Speed to match your server. For es103: World Speed 2×, Unit Speed 0.5×. Set My Player to your in-game name — this filters auto-generation to only your assigned requirements.

3 Import your villages

Option 1 — Script (automatic): Drag the gold bookmarklet button to your browser's bookmarks bar. Open TW → Recruit → Mass Recruit tab, click the bookmark — your troops are copied to clipboard. Come back here and click 📋 Paste Villages. This script only reads troop data already visible on the page — it does not interact with the game or send anything to the server.

Option 2 — Save HTML manually: Open TW → Recruit → Mass Recruit tab, press Ctrl+S → Save As → HTML Only. Back here, click 📄 Select HTML File and pick the saved file — villages are imported automatically. This is the safest option: no script runs on TW at all — you are simply feeding the saved HTML to the planner so it can read your units.

Use 🗑 Clear Villages to remove all villages and start fresh.

4 Add your villages (manual)

In My Villages, click + Add Village and fill in the coords, village ID, and troop counts (Axes, LC, Rams, Catapults, Nobles) manually.

🚀 Configuración Inicial

1 Base de Datos de Pueblos

No hay nada que descargar ni configurar — el planificador carga automáticamente los datos de pueblos y jugadores del mundo cada vez que lo abres, así que los nombres de pueblos, IDs y datos de jugadores están siempre actualizados.

Puedes consultar y buscar en los datos cargados desde la pestaña Base de Datos.

2 Configurar el mundo

En la barra superior, ajusta Velocidad Mundo y Vel. Unidades según tu servidor. Para es103: Velocidad 2×, Vel. Unidades 0.5×. Escribe tu nombre en Mi Jugador — esto filtra la generación automática a solo tus requisitos asignados.

3 Importar pueblos

Opción 1 — Script (automático): Arrastra el botón dorado a la barra de marcadores. Abre GT → Reclutar → Reclutamiento Masivo, haz clic en el marcador — las tropas se copian al portapapeles. Vuelve aquí y haz clic en 📋 Pegar Pueblos. Este script solo lee los datos de tropas ya visibles en la página — no interactúa con el juego ni envía nada al servidor.

Opción 2 — Guardar HTML manualmente: Abre GT → Reclutar → Reclutamiento Masivo, pulsa Ctrl+S → Guardar como → Sólo HTML. De vuelta aquí, haz clic en 📄 Seleccionar archivo HTML y elige el archivo guardado — los pueblos se importan automáticamente. Esta es la opción más segura: no se ejecuta ningún script en GT — simplemente le estás dando al planificador el HTML guardado para que lea tus unidades.

Usa 🗑 Borrar Pueblos para eliminar todos los pueblos y empezar de cero.

4 Añadir pueblos (manual)

En Mis Pueblos, haz clic en + Añadir Pueblo e introduce las coordenadas, ID del pueblo y tropas (Hachas, Lijas, Arietes, Catapultas, Nobles) manualmente.

⚔ Planning an Op

1 Import targets

Go to Targets → click ⚔ Off Targets and paste the BB-code op plan from your tribe forum. Lines with [unit]ram[/unit] = complete off, [unit]axe[/unit] = 1/2 off, [unit]snob[/unit] = noble train.

The easiest way: open the message or forum post where you received the op instructions, click Quote, and paste the whole quoted text. Everything — off sizes, times, coords, targets, players — is auto-imported.

For fake-only targets, use 💨 Fake Targets and paste one coordinate per line (e.g. 557|555). You can also add a target manually with + Add Target — set the type (Off / Fake) and requirements directly.

Use 🗑 Clear Targets to remove all targets and start a new op.

2 Auto-generate attacks

Go to Attack Plan → click ⚡ Auto-Generate. Pick a landing date, configure criteria (Power, Distance, Send Window) and options, then click Generate.

Attacks appear in the table sorted by send time. Any unassigned requirements (ran out of nobles or off villages) appear as red rows — review them and assign manually if needed.

3 Send your attacks

Click ⚔ Enviar on each row to open the TW rally point pre-filled with the correct troops and target. After sending, click ✓ Sent to mark it — the row moves to the bottom and greys out. If a village can no longer make it, click ♻ on its row to pick a replacement sender: every village that could still land inside the window is listed, and the free ones (not sending anything else in the plan) are marked 🏠.

4 Add attacks manually

Click + Add Attack in the Attack Plan section header to add an individual attack. Select the source village, target, type (Off / Fake / Snob) and landing time.

5 Save & backup

Data auto-saves to browser storage. Connect a local file via ⟁ Connect File for persistent storage. Use ↓ Export / ↑ Import in the top bar for manual backups.

Use 📋 Export BB Code to copy the full attack plan as a BB-code table you can post directly in your tribe forum.

⚔ Planificar una Op

1 Importar objetivos

Ve a Objetivos → haz clic en ⚔ Obj. Off y pega el plan BB-code del foro de tu tribu. Líneas con [unit]ram[/unit] = off completo, [unit]axe[/unit] = 1/2 off, [unit]snob[/unit] = tren de nobles.

La forma más fácil: abre el mensaje o post del foro donde recibiste las instrucciones de la op, haz clic en Citar, y pega todo el texto citado. Tallas de off, horarios, coordenadas, objetivos y jugadores se importan automáticamente.

Para objetivos solo de fake, usa 💨 Obj. Fake y pega una coordenada por línea (ej. 557|555). También puedes añadir un objetivo manualmente con + Añadir Objetivo — establece el tipo (Off / Fake) y los requisitos directamente.

Usa 🗑 Borrar Objetivos para eliminar todos los objetivos y empezar una nueva op.

2 Auto-generar ataques

Ve a Plan de Ataque → haz clic en ⚡ Auto-Generar. Elige una fecha de llegada, configura los criterios (Poder, Distancia, Ventana de Envío) y opciones, y haz clic en Generar.

Los ataques aparecen en la tabla ordenados por hora de envío. Los requisitos sin asignar (sin nobles ni pueblos off disponibles) aparecen como filas rojas — revísalos y asígnalos manualmente si es necesario.

3 Enviar los ataques

Haz clic en ⚔ Enviar en cada fila para abrir la plaza de reuniones pre-rellenada con las tropas y el objetivo correctos. Tras enviar, haz clic en ✓ Enviado — la fila baja al fondo y se oscurece. Si un pueblo ya no llega a tiempo, haz clic en ♻ en su fila para elegir otro origen: se listan todos los pueblos que aún llegarían dentro de la ventana, y los libres (que no envían nada más en el plan) llevan 🏠.

4 Añadir ataques manualmente

Haz clic en + Añadir Ataque en la cabecera del Plan de Ataque para añadir un ataque individual. Selecciona el pueblo de origen, objetivo, tipo (Off / Fake / Noble) y hora de llegada.

5 Guardar y hacer copia de seguridad

Los datos se guardan automáticamente en el navegador. Conecta un archivo local con ⟁ Conectar Archivo para almacenamiento persistente. Usa ↓ Exportar / ↑ Importar en la barra superior para copias manuales.

Usa 📋 Exportar BB Code para copiar el plan de ataque completo como tabla BB-code y pegarlo directamente en el foro de tu tribu.

🌾 Scavenging

1 Import a village

Drag the gold 🔖 Scavenging → Planner button to your bookmarks bar. In TW open Rally Point → Scavenging for the village, click the bookmark, then click 📋 Paste Scavenge Data here. Or save the page (Ctrl+S, HTML Only or Single File .mhtml) and use 📄 Select Saved Page. Repeat per village — each one is kept in the village dropdown.

The import reads the units at home, which of the four options are free / running / locked, and the world's scavenging speed (from the page's duration preview). Nothing is sent to the game.

2 Choose what to send

Untick a unit type to keep all of it at home, or type a number in Keep to hold back a reserve. The plan recalculates instantly. Only the carry capacity matters for scavenging — no troops are ever lost — so send whatever is idle.

3 Pick the goal

Resources / hour spreads troops across every free option so the combined income is highest — use it when you re-send as soon as runs return. Resources / run maximises one trip: everything goes to the best option, spilling down only when a Max duration is set — use it with the hours you'll be away (e.g. 8 overnight) so all runs are back when you are.

Why split at all? The same troops take the same time on any option (the higher one just pays more), but duration grows slower than capacity, so four smaller concurrent runs out-earn one big one — often by 50–90 %. The summary line shows the gain versus putting everything in the top option.

🌾 Recolección

1 Importar un pueblo

Arrastra el botón dorado 🔖 Recolección → Planificador a la barra de marcadores. En GT abre Plaza de reuniones → Recolección del pueblo, haz clic en el marcador y luego en 📋 Pegar Recolección aquí. O guarda la página (Ctrl+S, Sólo HTML o Archivo único .mhtml) y usa 📄 Seleccionar página guardada. Repite por pueblo — cada uno queda en el desplegable.

La importación lee las unidades en el pueblo, qué opciones están libres / en curso / bloqueadas y la velocidad de recolección del mundo (de la duración previa de la página). No se envía nada al juego.

2 Elegir qué enviar

Desmarca un tipo de unidad para dejarlo entero en casa, o escribe un número en Guardar para reservar parte. El plan se recalcula al instante. En recolección solo cuenta la capacidad de carga — nunca se pierden tropas — así que manda lo que esté parado.

3 Elegir el objetivo

Recursos / hora reparte las tropas entre todas las opciones libres para que la suma de ingresos sea máxima — úsalo si reenvías en cuanto vuelven. Recursos / viaje maximiza un solo envío: todo a la mejor opción, bajando a las demás solo si fijas una Duración máx. — úsalo con las horas que vas a estar fuera (p. ej. 8 por la noche) para que todo haya vuelto cuando regreses.

¿Por qué repartir? Las mismas tropas tardan lo mismo en cualquier opción (la superior solo paga más), pero la duración crece más despacio que la capacidad, así que cuatro envíos pequeños simultáneos rinden más que uno grande — a menudo un 50–90 % más. La línea de resumen muestra la ganancia frente a meterlo todo en la opción superior.
